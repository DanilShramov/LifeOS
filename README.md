# Life OS — версия 3

Мобильная личная система для iPhone. Все разделы изначально пустые: никакие финансовые суммы, долги, цели, привычки или планы заранее не заполнены.

## Структура
- Главная: пользовательская надпись, которую можно изменить; плитки разделов.
- Календарь: самостоятельный список дел и событий. Синхронизации с календарём iPhone нет.
- Циклы: 40-дневный цикл, разделённый на четыре списка задач по 10 дней. Задачи можно добавлять, отмечать выполненными, редактировать и удалять.
- Финансы: три пустые папки — «Финансовая подушка», «Крупные покупки», «Инвестиции». Можно добавлять свои записи.
- Стратегия жизни: цели на 1, 3 и 5 лет. Для каждой цели можно указать приоритет, этап выполнения, срок и описание.
- Карьера: работа, профессиональные планы и проекты, в том числе ресторанная платформа — добавляется как собственная цель.
- Летопись и впечатления: единый раздел для событий жизни, мест и впечатлений.
- Книги, фильмы, спорт и желания: пустые разделы.

## Использование
1. Откройте приложение на iPhone в Safari.
2. При желании нажмите «Поделиться» → «На экран Домой».
3. Откройте нужный раздел и добавляйте собственные записи.
4. Для циклов откройте раздел «Циклы», настройте номер и дату начала, затем добавляйте задачи в нужный десятидневный отрезок.
5. В «Стратегии жизни» добавляйте цели и задавайте горизонт, приоритет и этап.

## Сохранение и резервная копия
Данные хранятся локально в браузере устройства и автоматически сохраняются. Они не синхронизируются с GitHub или другими устройствами. В разделе «Настройки» можно экспортировать и импортировать JSON-копию. Перед очисткой приложения рекомендуется скачать резервную копию.

## Публикация / обновление на GitHub Pages
Замените в корне репозитория файлы `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `README.md`. Папку `icons` оставьте без изменений. Затем обновите страницу GitHub Pages. Для новой версии используется отдельный ключ локального хранения, поэтому прежние тестовые данные не будут перенесены в пустую структуру.
