# Life OS — версия 4

Мобильная личная система для iPhone. Все пользовательские записи изначально пустые: нет заранее внесённых финансовых сумм, долгов, целей, задач, привычек или планов. Названия основных папок и необходимых вложенных папок сохранены для навигации.

## Основные папки на главном экране

- **Календарь** — самостоятельный список дел и дат. Синхронизации с календарём iPhone нет.
- **40-дневные циклы** — один цикл разделён на четыре списка: дни 1–10, 11–20, 21–30 и 31–40. Задачи добавляются вручную, отмечаются выполненными, редактируются и удаляются. Номер и дата начала цикла настраиваются.
- **Стратегия жизни** — цели сгруппированы по горизонтам 1 год, 3 года и 5 лет. Для каждой цели можно открыть подробности, задать срок, приоритет, этап выполнения, описание и следующий шаг. Отдельной папки «Дом» нет: планы по дому и недвижимости добавляются здесь как обычные цели.
- **Финансы** — вложенные папки: «Финансовая подушка», «Крупные покупки», «Инвестиции / ИИС», «Доходы и расходы», «Долги и обязательства». Внутри нет предзаполненных сумм и записей.
- **Карьера** — вложенные папки: «Работа», «Ресторанная платформа», «Другие проекты». Ресторанная платформа находится внутри карьеры, отдельной главной плитки у неё нет.
- **Обучение**.
- **Здоровье и спорт**.
- **Летопись и впечатления** — единый раздел для событий жизни, мест, поездок и впечатлений.
- **Книги**.
- **Фильмы и сериалы**.
- **Желания**.
- **Собака**.
- **Дневник и заметки**.
- **Итоги года**.

## Управление

- Надпись на главном экране можно изменить.
- Плитки основных папок можно перемещать вверх и вниз.
- Внутри папок можно добавлять, открывать, редактировать и удалять свои записи.
- В стратегии жизни цели открываются отдельно и показывают этап, приоритет, срок и следующий шаг.
- Автосохранение работает в локальном хранилище браузера.
- В настройках доступны экспорт и импорт JSON-резервной копии.

## Установка / обновление GitHub Pages

Загрузите в корень репозитория файлы `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `README.md` и папку `icons` из этого архива, заменив одноимённые старые файлы. После публикации откройте сайт и обновите страницу. Для v4 используется отдельный ключ хранения `lifeos-data-v4`, поэтому приложение начнётся с пустой структуры; старые записи версии 3 не удаляются из старого ключа браузера.

## Важно

Это автономная PWA. Содержимое хранится в браузере конкретного устройства и не синхронизируется автоматически с другими устройствами или календарём iPhone. Регулярно скачивайте резервную копию из настроек.
