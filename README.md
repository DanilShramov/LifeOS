# Life OS — mobile-first personal PWA

## Что умеет эта версия
- Одна главная страница с плитками всех разделов.
- Создание, переименование, удаление и изменение порядка разделов.
- В каждом разделе сверху находится редактируемая сводка показателей.
- Внутри раздела можно создавать текстовые блоки, списки и папки/блоки.
- Любой заголовок, текст, показатель и цифра редактируются без изменения кода.
- Порядок блоков меняется стрелками вверх/вниз — удобно на сенсорном экране.
- Автоматическое сохранение в браузере.
- Экспорт и импорт полной резервной копии JSON.
- Мобильная компоновка для iPhone, установка как PWA и кеширование оболочки для офлайн-открытия.
- При обновлении исходной версии сохраняется прежний ключ `lifeos-data`; прежняя структура данных автоматически переносится в новые редактируемые разделы при первом запуске.

## Публикация на GitHub Pages
1. Скопируйте содержимое папки `life-os-pwa` в корень репозитория (не саму папку-обёртку).
2. Сохраните папку `icons` и её файлы.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Дождитесь завершения публикации и откройте адрес GitHub Pages.
5. На iPhone откройте сайт в Safari → Поделиться → На экран «Домой».

## Хранение данных — важно
Данные хранятся локально в браузере устройства через `localStorage`. Они не синхронизируются автоматически между iPhone и компьютером и не хранятся в GitHub. Для переноса используйте экспорт JSON на одном устройстве и импорт на другом. Регулярно делайте резервные копии.

## Обновление
При следующем обновлении заменяйте файлы `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` и `README.md`; папку `icons` оставляйте, если иконки не менялись. Service Worker имеет новый cache key, поэтому новая оболочка приложения должна загрузиться после обновления страницы/перезапуска PWA.
