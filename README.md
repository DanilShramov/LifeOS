# Life OS — PWA для iPhone

Первая версия личной системы управления жизнью. Интерфейс адаптирован под iPhone и desktop.

## Уже работает
- Главная панель с финансовыми показателями и прогрессом 40-дневного цикла.
- Финансовые операции: добавление, просмотр и удаление доходов/расходов.
- Автоматический расчёт распределения поступлений по заданным процентам.
- 40-дневный цикл с четырьмя результатами и статусами.
- Цели, проекты, летопись и заметки.
- 18 разделов-категорий системы.
- Экспорт и импорт резервной копии JSON.
- PWA manifest, service worker и offline app shell.

## Публикация через GitHub Pages
1. Создать отдельный публичный репозиторий, например `life-os`.
2. Загрузить содержимое этой папки в корень репозитория.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. После публикации сайт будет доступен по адресу `https://USERNAME.github.io/life-os/`.
5. На iPhone открыть ссылку в Safari → Поделиться → На экран «Домой» → включить «Открывать как веб-приложение» (если переключатель доступен) → Добавить.

## Важное про синхронизацию
Эта сборка пока хранит данные локально на устройстве (`localStorage`). Она не подключена к облаку и не должна считаться облачно-синхронизируемой. Для безопасной облачной синхронизации нужен отдельный Firebase-проект и настройка Authentication/Firestore с ограниченными правилами доступа. Не используйте проект FLO для личных данных. Пока облако не подключено, регулярно делайте JSON-резервную копию через Настройки.
